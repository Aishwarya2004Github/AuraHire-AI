# AuraHire AI 🚀

**AuraHire AI** is an intelligent recruitment and resume screening platform designed to modernize the hiring process through Natural Language Processing (NLP) and Machine Learning. It eliminates manual screening by automatically evaluating resumes, performing skill-gap analysis, and scoring candidates based on job relevance.

## ✨ Key Features
* **Automated Resume Parsing:** Seamlessly extracts information from PDF and Docx files.
* **Smart Skill Matching:** Compares candidate expertise against job descriptions using NLP.
* **Candidate Ranking System:** Scores and ranks applicants to highlight top-tier talent instantly.
* **Interactive Dashboard:** Provides a visual overview of candidate analytics and hiring trends.

## 🛠️ Tech Stack
* **Backend:** Python (Flask)
* **AI/NLP:** spaCy, NLTK, or BERT
* **Database:** SQLite / MySQL
* **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript
